## 👋 Giới thiệu

**Nhật ký học tập & ôn luyện** **SOC Analyst (Security Operations Center Analyst)**.
Giải các bài LAB **Blue Team Lab** trên [CyberDefenders.org](https://cyberdefenders.org), bao gồm:

- 🔎 Phân tích log, phát hiện dấu hiệu tấn công (IOC)
- 🧩 Điều tra sự cố an ninh mạng (Incident Response)
- 🧠 Phân tích mã độc, network forensic, memory forensic
- 🛠️ Sử dụng các công cụ: Wireshark, Splunk, Sysmon, Volatility, ELK, Autopsy...

> 🎯 **Mục tiêu:** Xây dựng nền tảng vững chắc về SOC/Blue Team ứng tuyển vị trí SOC Analyst.
